# مصحف «وعلامات»

مصحف المدينة النبوية تُعلَّم فيه مسائل كتاب «وعلامات: موسوعة جامعة في ضبط المتشابهات» للدكتور سعيد أبو العلا حمزة:
تضغط الآية الملوَّنة فتظهر مسائلها (المواضع المتشابهة ورقم الصفحة في الكتاب)، وفي تبويب ثانٍ فوائد المؤلف وتوجيهاته.

صفحة ثابتة واحدة (`index.html`) بلا بناء؛ تُنشر على Vercel كما هي.

- `data/w.json`: ١٧٥٤ مسألة: [رقم المسألة، السورة، الآية، العبارات المتشابهة، صفحة الكتاب، مواضع العبارة في المصحف].
- `data/f.json`: ٤١٥ فائدة: [السورة، الآية، صفحة الكتاب، النوع، النص، عبارة التنبيه].
- `data/q4/` و`fonts/qcf4/`: صفحات مصحف المدينة ١٤٤١هـ وخطوطها (مشروع quran-qcf4، البيانات برخصة MIT، والخطوط لمجمع الملك فهد).
